Redis Key Şemaları
otp:{phone}
STRING
Format: {6-digit-code}:{attempts}
TTL: 5 dakika · Max 3 yanlış deneme
otp_verified:{phone}
STRING
OTP başarılı doğrulama işareti
TTL: 30 dakika · Kayıt tamamlandığında tüketilir (DEL)
otp_cooldown:{phone}
TTL
SMS yeniden gönderme bekleme süresi
Cooldown geçmeden ikinci OTP isteği reddedilir
refresh_token:{token}
STRING
Value: user_id · TTL: 7 gün (yapılandırılabilir)
Kullanımda eski silinir, yeni yazılır (rotation)
rl:login_phone:{phone}
INCR
Login rate limit — telefon başına
Max 5 istek / 15 dakika
rl:login_ip:{ip}
INCR
Login rate limit — IP başına
Max 30 istek / 15 dakika (NAT koruması)
rl:otp:{phone}
INCR
OTP gönderme limiti
Max 3 istek / saat
Rate Limit Mimarisi
func RateLimit(rdb *redis.Client, cfg Config) Handler { return func(c *fiber.Ctx) error { key := "rl:" + cfg.KeyFunc(c) // Atomik sayaç artırma count, _ := rdb.Incr(ctx, key).Result() if count == 1 { // İlk istek → TTL başlat rdb.Expire(ctx, key, cfg.Window) } if count > int64(cfg.Max) { return response.TooManyRequests(c, ...) } return c.Next() } }

Kimlik Doğrulama

JWT HS256 + OTP Mekanizması

JWT Token Yapısı
// generateToken() — HS256 imzalı claims := jwt.MapClaims{ "user_id": user.ID, // UUID "role": user.Role, // admin|farmer|customer "exp": now + jwtExpiry, "iat": now, } // Middleware: RequireAuth → RequireRole → RequireActiveUser // Defense in depth: exp claim explicit doğrulanır // Refresh token: 32-byte crypto/rand → hex string // Redis'te: refresh_token:{hex} → user_id
Middleware Zinciri
RequireAuthJWT parse + DB user doğrulama
RequireRole("farmer")Locals'tan rol kontrolü
RequireActiveUserstatus == "active" kontrolü
🔐 bcrypt maliyet 12 (~300ms/hash). Şifre asla plain text saklanmaz. Login'de CompareHashAndPassword
OTP Akışı — Detay
① Send — crypto/rand ile 6 haneli kod üret
Redis: otp:{phone} = "123456:0" (TTL 5 dk)
Dev ortamda SMS yerine stdout'a yaz
↓
② Verify — Redis'ten kodu oku, karşılaştır
Yanlış → attempts++ → TTL korunarak güncelle
3. yanlış → key DEL (geçersiz)
↓
③ Başarı — otp:{phone} DEL, otp_verified:{phone} SET
30 dakika pencere — müşteri kaydı veya çiftçi başvurusu için
↓
④ Müşteri Kaydı — otp_verified kontrol → tüket (DEL)
Aynı OTP doğrulaması başka kayıt için kullanılamaz
📱 SMS: Netgsm (prod) · DevProvider stdout (dev)
Format doğrulama: ^05[0-9]{9}$ — 11 karakter
